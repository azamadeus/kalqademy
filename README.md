# Kalqademy

Симулятор куратора. У каждого ученика есть тип MBTI, эго-состояние (Родитель / Взрослый / Дитя) и цель. В ходе игры с учениками случаются проблемы, куратор выбирает вариант реакции и получает обратную связь. За хорошие решения куратор получает опыт и растёт в уровне.

> MBTI здесь описывает склонности, а не приговор.

## Запуск

```bash
npm install
npm run dev
```

```bash
npm run build
npm test
```

## Структура

- `src/data/students.ts` — ученики
- `src/data/scenarios.ts` — ситуации, варианты и модификаторы по типу ученика
- `src/game/engine.ts` — правила: оценка выбора, опыт, уровни
- `src/game/storage.ts` — сохранение прогресса в `localStorage`
- `src/App.tsx` — интерфейс

Контент отделён от кода: чтобы добавить ученика или ситуацию, достаточно дописать данные в `src/data`.
