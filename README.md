# Kalqademy

Тест-тренажёр для кураторов ЕНТ по методике ALQA Academy.

1. **Ученик.** Случайный или собранный вручную из списка: тип MBTI (16) и доминирующее эго-состояние (5). Появляется аватар и легенда: мечта и вуз, учёба, семья и онлайн-курс, «тараканы в голове» (страхи, чувствительная тема).
2. **Тест.** 10 ситуаций с ответами ученика. В каждой нужно выбрать лучший из четырёх ответов куратора. Верный ответ даёт балл, в точку или нет видно сразу.
3. **Результат.** Итоговый балл и подсказки только по тем вопросам, где вы ошиблись: какой ответ был лучше и почему.

Верный ответ считается по данным из материалов ALQA: для типа, эго-состояний, драйверов и чувствительной темы выписаны «что работает» и «что убивает мотивацию», а варианты ответов размечены признаками (`src/quiz/needs.ts`, `src/quiz/tags.ts`). Часть вопросов строится из слов самого ученика, а два вопроса учат определять чувствительную тему по языку тела и поведению. Прежде всего верный ответ зависит от ситуации, типа MBTI и эго-состояния ученика (`src/quiz/quiz.ts`), поэтому у разных учеников он разный. Интерфейс на русском и казахском (переключатель в шапке; перевод на казахский черновой, `src/i18n/kk.ts`).

> MBTI, эго-состояния и «чувствительные темы» это модели-гипотезы для тренировки общения, а не диагноз. Они не определяются по внешности. При тревожных сигналах куратор привлекает школьного психолога.
