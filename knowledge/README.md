# База знаний (knowledge)

Структурированные заметки по четырём книгам. Это отдельный слой данных: приложение их пока не читает, но тест `src/knowledge.test.ts` проверяет целостность.

| Файл | Что внутри |
|---|---|
| `sources.json` | какие книги, сколько знаков, для чего используются, что исключено |
| `bourbeau.json` | пять травм: маска, страх, поведение, слова-маркеры, как выглядит исцеление; связи между травмами; принципы распознавания; зеркало; шаги исцеления |
| `maxwell_25_ways.json` | 25 практик общения: идея, «забыть / спросить / сделать / помнить», признаки ответа, где применить у нас |
| `maxwell_21_laws.json` | 21 закон лидерства и что он значит для куратора |
| `maxwell_leader_2.json` | 10 глав «Воспитай в себе лидера 2.0»: идеи и применение |
| `crosswalk.json` | связи травм, эго-состояний, драйверов, позиций ТА и практик |
| `ANALYSIS.md` | анализ, что можно добавить в систему |

Тексты пересказаны своими словами. Полные тексты книг в репозиторий не входят: `python3 scripts/extract_books.py <книга>` извлекает их локально в `knowledge/raw/` (папка в `.gitignore`).

Описания внешности и телосложения по травмам из книги Бурбо сознательно не вносятся.
