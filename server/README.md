# Relay для живого режима

Нужен, если игра должна быть открыта для всех по ссылке и QR (без входа в claude.ai).

```bash
cd server && npm install && npm start      # слушает порт 8787 (PORT=...)
```

Фронтенд собирается с адресом ретранслятора:

```bash
VITE_RELAY_URL=wss://ваш-домен npm run build
```

Ведущий отправляет события по секретному токену, игроки только ставят «присутствие» (имя и ответ). Данные нигде не хранятся.

Протокол и нагрузка: `../docs/LIVE_BACKEND.md`. Нагрузочный тест: `node loadtest.mjs ws://localhost:8787 КОД 200`.
